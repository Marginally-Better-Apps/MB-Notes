# Collaboration test gate

`ios-test.sh` builds the React client, runs protocol tests and browser interaction tests, then runs an optimized Release native app with Gala console/screenshot capture enabled. Xcode tests run on a temporary iPad simulator. Local tests finish first, then a second iPhone simulator hosts an imported note for the native guest test. Both are deleted afterward. Test runs use an isolated library guarded by `MBNotesUIAutomation=YES`; normal builds never reset the user's notes.

Native UI tests click Live Collaboration, place and save text, draw a stroke, move a laser, display the QR invitation, dismiss the session, and restart the app to verify rendered text with Vision OCR and the saved stroke’s indigo pixels on the native page. A native guest also joins the other iOS app through its invitation URL, adds text and ink, and verifies those changes in the owner’s saved model. The test fixture contains an imported PDF background. Inspect screenshots to check paper shape, imported content, the keyboard, and menus. After XCTest finishes, a browser guest joins a fresh native owner using the published React client, writes text and ink, and checks the owner’s saved state. The gate exports XCTest attachments alongside Gala screenshots/logs.

The shared protocol tests verify ordered concurrent edits, persistence-before-acknowledgment, failed-save rejection, retry deduplication, reconnect snapshots, author-scoped undo, admission limits, invalid input, and laser separation. Swift tests verify fragmented/coalesced frames, oversize rejection, nine loopback TCP guest streams, saved native text/ink, and preserving preexisting ink while undoing a shared addition.

Browser tests exercise two real clients through public PeerJS signaling, basic pen/text, laser expiry, a deliberately closed WebRTC connection, reconnection, author-scoped undo, host closure, pasted invitation joining, relay setting validation, large background/ink transfers, and switching between portrait and landscape pages without mixing their content. `npm run test:relay` is an explicit provider audit. The bundled default relay failed; do not report that check as passing or treat a direct connection as relay evidence.

Physical devices remain required for nearby discovery, QR scanning, and campus-network testing. See [COLLABORATION.md](COLLABORATION.md) for the network test matrix and current limits.
